# Come Aldo aggiorna il sito

Accedi a GitHub, apri il repository e modifica direttamente il file Markdown desiderato.

- Concerti in italiano: `studio/concerti.md`
- Concerts in English: `studio/en/concerts.md`
- Biografia: `studio/biografia.md`
- Discografia completa: `_includes/discography-list.md`
- Progetti: `studio/progetti.md`
- Prime esecuzioni: `studio/prime-esecuzioni.md`
- Ricerca: `studio/ricerca.md`
- Pubblicazioni: `studio/pubblicazioni.md`
- Stampa: `studio/stampa.md`
- Contatti: `studio/contatti.md`

Procedura:

1. Apri il file.
2. Clicca l’icona della matita **Edit this file**.
3. Modifica il testo.
4. Clicca **Commit changes**.
5. Attendi uno o due minuti: GitHub Pages aggiorna automaticamente il sito.

Per aggiungere un concerto, copia una voce esistente in `studio/concerti.md`, cambiane data, luogo e programma, poi aggiorna anche `studio/en/concerts.md`.

La pagina pubblica mostra soltanto “Sito in preparazione”. L’anteprima completa si apre aggiungendo `/studio/` all’indirizzo del sito.
